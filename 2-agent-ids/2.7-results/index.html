3. How to read this

  • The agent catches almost everything, including encoded evasions and reconnaissance — the kinds of attacks that slip past signatures.
  • It still raises more false alarms (~7 of 71 benign requests) than the WAF (2) or Suricata (0). The original hypothesis “the agent reduces false positives” turned out to be wrong: on this data the IDS had none to reduce.
  • The lead over the WAF comes from recon (20 vs 8): a scan or password-guessing burst is only suspicious as a sequence, and CRS has no rule for that.
  • The data source matters more than the model. agent_ids — the same LLM fed only Suricata alerts — scores like the plain IDS. The extra catches come from reading the web log.
  • The remaining false alarms are mostly logins with DVWA’s default accounts on the brute-force page.
  • confidence is well calibrated (ECE 0.04); the MITRE technique is right for 85% of caught attacks.

4. Prompt v3 → v4

Prompt v4 makes the model write its evidence before its verdict and adds one worked example (“a plain page name is normal use; ../ is traversal”). It was chosen on the dev set against a criterion fixed in advance, before any test run. On test it removed the six fi/?page=<name>.php false alarms (FPR 0.18 → 0.10), at the cost of one new false alarm and one more missed directory-scan request. The two versions’ intervals still overlap, so treat the improvement as real on those cases but not yet firmly proven.
