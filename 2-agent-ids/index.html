Agent-IDS — Hybrid IDS + AI Agent

Agent-IDS is a lab that puts an AI agent next to a classic intrusion detection system and measures, with numbers, whether the agent actually makes better decisions.

A vulnerable web application (DVWA) sits behind Nginx and an OWASP CRS WAF. Suricata watches the network traffic and raises alerts. An AI agent built with LangGraph reads those alerts and the web server’s access log, asks a local LLM (Qwen2.5-14B on Ollama, running on an AWS GPU) what each request is, and decides to log, warn or block the source IP. A dashboard shows every decision, and risky blocks can wait for a human to approve them.

The project then runs a controlled A/B experiment: the same 147 labeled requests are replayed against five decision modes (plain IDS, block-every-alert, WAF, the agent, and the agent limited to IDS alerts), five times each, and scored with confidence intervals.
